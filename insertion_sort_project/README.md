# Mini Project: Empirical Analysis of Insertion Sort

## Objective
Implement insertion sort, count comparisons and shifts, measure its runtime on sorted,
reverse-sorted, and random inputs for sizes 100–5000, plot measured growth, and compare
with merge sort.

## Requirements
- Python 3.10 or newer
- `matplotlib`

## Run on Windows 11
1. Install Python 3.10+ from https://www.python.org/downloads/ and enable **Add Python to PATH**.
2. Extract this ZIP to a folder.
3. Open PowerShell in that folder.
4. (Recommended) Create and activate a virtual environment:
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
5. Install the dependency:
   ```powershell
   py -m pip install -r requirements.txt
   ```
6. Run the tests:
   ```powershell
   py -m unittest -v
   ```
7. Run the benchmark experiments:
   ```powershell
   py run_experiments.py
   ```
8. Find the results in `results/` and plots in `plots/`.

If PowerShell blocks virtual-environment activation, you can skip activation and run
`py -m pip install -r requirements.txt` and `py run_experiments.py` directly.

## Project structure
- `src/sorting.py`: insertion sort with comparison/shift counters and merge sort.
- `run_experiments.py`: deterministic data generation, repeated timing, CSV output, plots, summary.
- `test_sorting.py`: correctness and operation-count tests.
- `results/benchmark_results.csv`: measured benchmark records generated by the experiment script.
- `results/summary.txt`: compact summary generated from the measured results.
- `plots/runtime_comparison.png`: measured runtime curves and merge sort comparison.
- `plots/growth_analysis.png`: normalized measured curves against O(n) and O(n²) references.
- `report/report.md`: one-page-style academic report source.
- `report/report.pdf`: generated one-page PDF report.

## Measurement notes
The script uses `time.perf_counter()` and reports the median of three runs. The random
input is reproducible because a fixed seed is used. Wall-clock timings can vary across
machines. The comparison and shift counters are defined in `src/sorting.py`.
